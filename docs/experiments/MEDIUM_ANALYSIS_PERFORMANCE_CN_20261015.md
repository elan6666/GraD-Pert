## 已实现机制与验证边界

| 机制 | 消除的工作 | 保留的统计语义 |
|---|---|---|
| GPU充分统计后回传 | 不将每行16384原型logits复制到CPU；每头只回传O(K)的概率和、命中数和标量和 | 与原NumPy版相同的FP64概率、熵、JS、argmax命中和logit标准差；不抽样原型 |
| 身份选择前移 | 先按相同基因ID选择128个token，再回传；不复制随后丢弃的token | 相同细胞、基因、特征与同基因跨control分组 |
| 小Gram谱 | n<d时分解n×n的XXᵀ/n，代替d×d的XᵀX/n | 相同非零特征值、有效秩、方差；保留FP64中心化和退化判定 |
| 分阶段计时 | 标记数据装配、前向、统计和三项梯度 | CPU wall与CUDA kernel时间分开；嵌套区域不能直接相加 |

# 五组消融：中等规模诊断共同中文报告

五组冻结第4轮 last.pt 的补测已经完成。**本次最值得关注的是：更低的蒸馏 loss、更尖锐的原型和更高的混合表征秩，并没有自动对应更好的未见表达基因预测。** 本报告给出同口径数据与限制，不据此自动更改基线或启动实验。

训练过程中保存的历史小probe、本次冻结权重补测、原正式测试结果分开列示。没有重训，没有 optimizer／EMA／center 更新；单seed结果不能证明某组件长期或跨数据集稳定有效。

## 1. 五组做了什么

|实验|相对同一恢复结构的改动|
|---|---|
|DP|四个原型层 weight_norm＋首轮冻结原型参数|
|FN|FFN 输入改为 Pre-LayerNorm|
|FG|FFN 激活模板改为 GELU|
|FB|关闭约定 FFN／映射 Linear 的 bias（不是删掉模型所有 bias）|
|PO|预测头改为 Softplus 绝对非负表达输出|

共同训练口径：Jurkat cap40，seed1，4 epoch，global batch400（每卡微100×双卡×累积2），原配置与权重不改；正式测试复用第4轮 last 的封存收据，不重新选best。GenePT共享映射及其规格以冻结配置为准；FB仅关闭约定FFN／映射的bias，不扩展成注意力及所有归一化偏移的删除。

## 6. 表征：FN／FB的混合秩高，但单细胞内部Response基因差异更集中

有效秩按中心化协方差特征值λ归一化p=λ/Σλ，r_eff=exp(−Σp log p)；相对方差=tr(C)/(tr(C)+‖μ‖²)。这里C用样本二阶中心矩1/N归一化。有效秩不是向量宽度；所有这些主表示仍为256维。

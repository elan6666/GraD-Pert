# 第二轮：区分投影头条件与主干 CLS 分散压力

日期：2026-10-22。首轮结束后设计；目标是解决任务相关表征退化，四轮作为阶段复盘点，未解决则继续证据驱动的迭代。每个新臂从头训练2轮；历史测试不参与这轮方案选择。

## 问题与依据

同细胞128基因的最终秩RS-B0为1.458、RS-RI为11.044，且总能量近似不变。RI保留token差异的机制证据成立，但Response CLS的混合秩21.36→15.79、同control异扰动区分度减弱，尚不能升级为最终基线。

Teacher RI Global0在投影头前有效秩17.35、相对方差0.002652；瓶颈降到4.35和0.000402。温度缩放logits标准差仅0.0164，样本熵9.703896接近16384原型的均匀熵9.704061。这提示两个可区分的解释：入口数值条件/非线性映射进一步压缩已有差异；主干CLS没有足够压力保留跨输入变化。

## 实验

|实验|相对RI仅改变什么|预期与可失败假设|
|---|---|---|
|R2-RI|重复RI，同初始化和预算|在新源码下复核对照与诊断，保留原RS-B0锚点|
|R2-HN|仅SSL2 CLS投影头入口加FP32 LayerNorm256，eps1e-6，scale/bias可训；Student/Teacher同构|若入口条件是关键，瓶颈差异与有效训练信号应增强，并能回传到主干；只变尖不算解决|
|R2-KL|仅ssl2_koleo从0变0.1|若主干缺少分散压力，CLS正确/错配结构和可用差异应改善；只提高batch/context差异或扰动身份不算成功|

两项分别运行，不叠加。HN保留原MLP、L2和原型，SSL1/iBOT头不加Norm。逐样本LayerNorm不等于跨样本去中心，也不能恢复已经丢失的信息。这是定位假设，并非已证明修复。

KoLeo对两个Student Global的Response CLS分别L2后，取合格最近邻的负对数距离，两个Global取mean，权重0.1是项目预注册初值。官方DINOv2训练对两Global取sum，因此不能称为同梯度尺度复现。保留已有同扰动排除规则，完整有效群体跨微批、跨GPU可微收集；**没有按context限制邻居**，其潜在batch/condition-ID效应必须在诊断中检查。它可能推开生物学相似的不同扰动，这是失败风险。

## 共同训练与诊断

- 从头2 epoch，seed1，global320，初始计划80×双卡×累积2；相同LR/EMA端点和相对进度。无逐轮validation/best。KoLeo延迟反向增加显存，先做10步/恢复/双卡eval128门；容量不足时停止，由主会话以共同配置/新ID修复，不让某一臂静默换batch。
- 沿用原中等1335条件/5317行、深度128/506、梯度32/125、同一32条件×4control交叉面板，真实表达裁剪/mask摘要匹配。每臂完成立即验证18指标+中等诊断+交叉分析。
- 原始RS-B0、首轮RS-RI和第二轮R2-RI均保留身份；新源码与旧源码比较须明确版本并以关闭路径回归核对。重复锚点可发现执行/版本差异，不将差异默认归因于新机制。
- 保留主干CLS→projector瓶颈→原型的三级统计，Student/Teacher分列。保留token单细胞/混合/同gene跨control轴。Global/Local正确配对、同条件异control、同control异条件均在context内汇总；不把相关pair当独立N。
- CE=Teacher H+KL；同一Teacher锚点正确/错配CE差=KL差，只作为一项证据。低H、低CE、高rank均不单独验收。
- 全部、见过/未见表达基因的18验证Pearson与预测误差/幅度一起判断。测试延期至设计锁定。

## 决策与后续

HN只改善head而不改善主干/条件间隙/任务价值：仅支持目标统计改变，下一轮不盲目累加。KL只提高rank/距离而削弱同样本一致性或预测：不保留该分散项。若一项改善多轴结构且无明显预测代价，作为下一轮候选，同时保留原B0锚点；仍需稳定性、响应价值与长训练确认。两项都失败则根据定位证据研究CLS生成/读出、视图信息保留或目标冲突，而非继续降低温度。

历史DP/DP2已经使Teacher更尖锐并提高JS，但主干/预测没有同步改善，因此本轮不重复尖锐化组合。两轮EMA初始化参数累计系数约22%，这影响短预算解释，但所有新臂日程相同；不同时改EMA。

## 表征

固定前缀中的基因表示差异增强，但不是生物学功能验证。Response 基因有效秩

## 蒸馏目标

蒸馏① condition Teacher JS 0.0335→3.7586，最终 128 个样本用了 103 个
argmax 原型，最大单原型占比 4.7%，不支持此探针里的常量目标。实际配对 CE
9.0250→2.9667，Teacher 熵 8.5002→2.8480，KL 0.5248→0.1187。
约 **93.3% 的 CE 下降来自 Teacher 熵下降**，约 6.7% 来自 KL 下降。
目标既更尖锐也更依赖样本，不能把 CE 下降全部解释成 Student 拟合进步。

蒸馏② iBOT 的 Teacher 头前缀 128 个 token 全部选择同一 argmax，JS 0.00972，
分布差异较小。但有效边际原型 629.6、平均 top1 概率 0.2667，并非单原型
one-hot；这不等于全部细胞或全部 token 坍塌。该前缀与实际 CE mask 配对行
不同，后者 Teacher 熵 5.0466、KL 0.02937，不能混用两组熵。扩大分细胞、视图、
基因覆盖的诊断可另议；本轮没有额外 GPU 前向。

## 输出及梯度

最终固定训练探针预测 MSE 0.041067，相比复制 control 的 0.076047 降低 46.0%。
Δ RMS 0.18386，对随机配对真实效应 RMS 比 0.6667，负预测占比 0%，最差 1%
元素贡献 18.47% 误差。该探针只含训练可见表达基因，不是未见组结果或生物学
反事实校准。

最终共享图梯度范数：预测 0.07786、SSL1 1.94675、SSL2 0.54023；SSL1 约为
预测的 25 倍。cos(预测,SSL1)=0.12998，cos(预测,SSL2)=−0.10281。
蒸馏仍是共享图更新的重要来源，后者局部冲突值得跨 epoch 和更广样本核查；
一次负余弦不能判定辅助任务无效。

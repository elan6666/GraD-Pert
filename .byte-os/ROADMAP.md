# Roadmap

## v0 delivery (active)

1. Foundation: Git/package/test harness, active design migration, provenance.
2. Contracts: strict 30-config matrix, schemas, hashes, splits, controls,
   artifacts, server topology.
3. Data: five source adapters, canonicalization/QC/readiness and GEARS views.
4. Native model: graph/view/loss/teacher/predictor/train/resume.
5. Baselines: three nonlearned plus isolated GEARS/TxPert runners.
6. Evaluation: three Pearson headlines, frozen metric union, summaries,
   notebook-ready evaluation bundles.
7. Server: exact commit sync, environment locks, five data gates, `K_head` fit,
   pilot then formal learned runs, small-result sync.
8. Quality/delivery: review, three evidence-led iterations, fresh review, docs.

## v1 improvements

- Only items discovered through v0 failures that improve reliability,
  observability, throughput, or artifact usability without changing the model
  or experiment question.

## Later opportunities
